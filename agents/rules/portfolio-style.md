# Video Portfolio Development Rules
- Tech Stack: Next.js 15, TypeScript, Tailwind CSS, Framer Motion.
- Theme: Ultra-modern dark mode (slate-950 background, vibrant accents like emerald or violet).
- Performance Focus: Optimize all image inputs using Next.js `<Image />` component. Lazy-load all video embeds.
- Component Design: Code must be modular. Keep UI components separate from layout screens. Use Lucide React for icons.
